# Security policy

Please report vulnerabilities privately to the repository owner instead of opening a public issue. Include the affected route, expected impact and a minimal reproduction. Do not include live provider credentials, authorization tokens or copyrighted media URLs.

The project accepts only official, licensed or explicitly embeddable sources. Reports involving DRM/geoblock bypass, token extraction, protected manifest scraping, referer spoofing, restreaming or unverified IPTV will not be implemented as features.
